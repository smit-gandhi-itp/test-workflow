# Math Utils

A simple Python utility module providing basic mathematical operations.

## Features

- **add(a, b)**: Returns the sum of two numbers
- **multiply(a, b)**: Returns the product of two numbers

## Usage

```python
from math_utils import add, multiply

# Addition
result = add(5, 3)
print(result)  # Output: 8

# Multiplication
result = multiply(4, 7)
print(result)  # Output: 28
```

## Running the Demo

You can run the module directly to see a demonstration:

```bash
python math_utils.py
```

## Requirements

- Python 3.6 or higher
